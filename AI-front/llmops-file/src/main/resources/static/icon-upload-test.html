Icon 上传与展示测试

该页面用于测试 IconController 小文件上传与图片展示。
图片会上传到 icon bucket，按 {project}/{uniqueFileName} 存储，并返回可直接展示的 URL。

说明

  • 上传接口：POST /api/icon/upload
  • 取 URL 接口：GET /api/icon/url?objectKey=...
  • 文件较小，使用普通上传，不走分片上传。
  • 后端会自动重命名文件，避免同名覆盖。
  • 图片 URL 可直接用于前端 <img> 展示。
